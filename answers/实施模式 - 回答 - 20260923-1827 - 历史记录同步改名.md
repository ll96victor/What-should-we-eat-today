```text

D. 重命名那一轮自己的记录 → 保留旧名（否则记录自相矛盾）
```

## 5. 执行方式（按 Skill 的中文批量替换安全规范）

该规范源于一次真实的编码事故（PowerShell 5.1 默认编码把中文 Markdown 改乱码），
本轮逐条遵守：

| 规范要求 | 本轮做法 |
|---|---|
| 不用 PowerShell 默认编码 | ✅ 全程 Node + `readFileSync/​writeFileSync` 显式 `'utf8'` |
| 替换前先备份 | ✅ 11 份文档备份到 `history/*.before-20260923-v6.md` |
| 替换前跑空跑清单 | ✅ A/B 类先输出逐条 before→after 对照 |
| 替换后抽样检查中文 | ✅ 抽查关键行 |
| 替换后扫描乱码标记 | ✅ 扫 401 个文件，无乱码 |
| 旧串残留与乱码**两者都扫过**才算完成 | ✅ 两项均扫 |

**C 类的特殊处理**：C 类**没有**做字符串替换，而是逐处用**精确字符串匹配 + 断言命中**
的方式追加完成说明。因为 C 类的句子本身是准确的，只是**结论过期**——
替换会破坏语义，更新状态才是对的。
